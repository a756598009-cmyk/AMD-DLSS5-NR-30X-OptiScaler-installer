OpenNR RX 7000 confirmation kit

Thanks for running the speed kit. We took what it found: the next OpenNR runs part of the RX 7000 network as
ready-made machine code (ACO) where your card ran it faster, and the faster ViT attention from 1706x960 up. This
kit runs the network exactly as that update will ship, so we can check the picture and the speed before it goes
out. It does not install anything and does not touch your games or drivers.

What it runs, on a test picture at 6 sizes (648p to 4K):
 - the network as OpenNR 0.6.9 runs it today (to compare the speed);
 - the next version with ACO off;
 - the next version as it installs (ACO on), and the same with the large (310.8) model at 720p and 1080p.

1. Unzip this folder anywhere (for example your Desktop). Keep about 1 GB free there.
2. Optional, saves a download: copy dlssnr-small.bin and dlssnr.bin from an earlier kit's files\dlssnr-amd folder
   (or from a game's dlssnr-amd folder) into this kit's files\dlssnr-amd folder. Without them the kit downloads them
   (about 260 MB) from the same place the OpenNR installer uses.
3. Close games and other heavy programs (browsers with video too).
4. Double-click run-test.bat. If Windows says it protected your PC, click "More info", then "Run anyway".
5. Wait. It takes about 10 to 15 minutes, plus the download.
6. When it says "Done", send us the one file it names:
   OpenNR-RX7000-confirm-result-<date>.zip (next to run-test.bat; the folder opens by itself).
   Please also tell us your card and whether anything looked odd (black screen, driver reset).

If the window closes or the PC freezes, restart, then zip the "result" folder, send it and tell us what
happened.

You can delete the whole folder afterwards.
